# 英语自学包 · 分级阅读模块

英语分级阅读自学材料，按**可理解输入（i+1）**的思路组织：每篇文章控制生词比例，配套生词全景、标注原文与两篇衍生文，靠重复遇见把词固化下来。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `1.html` … `5.html` | 阅读包第 1–5 篇（含《The Rise of Short Video》《The Blind Box Craze》《Choosing a Career Path》），每篇含生词全景、标注原文、两篇衍生文 |
| `连载-A-县城小店.html` | 连载世界 A，微信聊天/对话体复习文 |
| `连载-B-大学最后一年.html` | 连载世界 B |
| `连载-C-一个人的长途.html` | 连载世界 C |
| `ABCmap.html` | 模块地图 + 跨篇词汇账本，追踪每个词的重遇次数 |
| `基础词表.html` | 初中级基础词参考表 |
| `compulsory-words.md` | 课标词表（义务教育 2022 版 · 1896 词） |
| `function-words.md` | 功能词表 |
| `sync-map.py` / `同步ABCmap.cmd` | 词汇账本同步脚本 |
| `连载设定.md` | 连载的世界设定与后续钩子 |

## 阅读顺序

从 `1.html` 开始，每篇页脚有「下一篇」链接；想复习已学词时走连载。词汇账本统一在 `ABCmap.html` 查看。

## 标注约定

- **下划线**：核心词，需要掌握
- **浅底阴影**：语块（chunk）
- **灰色内联注释**：认知词，词本身不着色，能用构词法推导
